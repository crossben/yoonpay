# ADR-0008 — Name "Yoon", namespace `yoonpay`

- Status: accepted
- Date: 2026-09-29

## Context
Name check on 2026-09-29: `yoon` is taken on GitHub, Docker Hub, npm (package)
and yoon.dev / yoon.io / yoon.sn. `yoonpay` was free on GitHub, Docker Hub, npm,
Packagist, Maven Central, and yoonpay.dev / .io / .sn had no DNS.

## Decision
Product name **Yoon**; every namespace uses **`yoonpay`**: GitHub `yoonpay/yoon`,
image `yoonpay/yoon`, Maven `dev.yoonpay`, Packagist `yoonpay/yoon-php`, npm
`@yoonpay`, domain `yoonpay.dev`.
